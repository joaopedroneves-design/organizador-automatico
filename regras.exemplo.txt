# =====================================================================
#  REGRAS DO ORGANIZADOR AUTOMÁTICO
#  Cada linha:   palavras do nome do arquivo   =>   pasta de destino
# =====================================================================
#  - Separe as palavras com vírgula. Maiúsculas e acentos não importam.
#  - A palavra tem que aparecer inteira no nome: "edo" não pega "credo".
#    Termine com * para valer o começo da palavra: oscila* pega "oscilações".
#  - Palavras que começam com ponto são extensões: .exe, .vhd
#  - O destino começa na Área de Trabalho. Para Downloads, comece com DOWNLOADS\
#  - Vale a PRIMEIRA regra que combinar, de cima para baixo.
#  - Uma linha só com "=> pasta" (sem palavras) vira apenas um botão na janela.
#  - Os botões da janela "Para qual pasta vai?" seguem a ordem deste arquivo.
#  - Pode editar à vontade: o organizador relê este arquivo sozinho.
#  - Semestre novo? É só trocar as matérias abaixo.
# =====================================================================
